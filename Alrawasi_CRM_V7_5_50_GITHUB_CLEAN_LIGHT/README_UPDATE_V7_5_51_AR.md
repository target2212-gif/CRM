# تحديث الرواسي CRM V7.5.51 — الإحصائيات والدمج الآمن

## ما الجديد
- فصل «الشركات الفريدة التي تم التواصل معها» عن «محاولات التواصل المسجلة» في لوحة التحكم.
- احتساب الشركة مرة واحدة على مستوى الفريق في إجمالي التقارير الشهرية، مع الاحتفاظ بإحصائيات كل موظف على حدة وإظهار جميع محاولاته.
- بقاء لون البطاقة أزرق لخدمات المقاولين، وبرتقالي إذا سجّل القسمان تواصلاً، مع الحفاظ على وضوح النصوص.
- عند تفعيل DATABASE_URL ونجاح حفظ Neon، تتحول أيقونة السحابة بجانب المستخدم إلى علامة نجاح، وتختفي الرسائل المتكررة المزعجة. يستمر التحذير الحقيقي عند غياب التخزين الخارجي أو فشل عملية حفظ لقطة Neon.
- توفير merge_latest_contacts_into_neon.py لفحص سجلات JSON وإلحاق المفقود دون استبدال النسخة الحية بالكامل.

## مهم جدًا قبل الاستيراد
- **هذا المشروع لا يحتوي على أي سجلات عملاء، ولا يحتوي على ملف JSON المرفوع.** لا ترفع نسخ البيانات أو كلمات مرور Neon إلى GitHub.
- أحدث نسخة مصدر (2026-10-13 18:50:21) بها 17,127 شركة و366 عملية تواصل تخص 325 شركة مختلفة.
- آخر فحص سابق لـNeon كان 351 عملية. **لا يمكن معرفة عدد عمليات الدمج الحقيقي إلا بأمر المعاينة المباشرة**.
- المعاينة والدمج يتطلبان رابط DATABASE_URL الخاص بـNeon **التجريبية فقط**، محفوظًا في متغير بيئة على جهازك.
- إيقاف استخدام CRM التجريبي لجميع الموظفين أثناء التطبيق **إلزامي**؛ لأن الإصدار الحالي يستخدم لقطة SQLite كاملة على Neon، ويمكن أن تعيد عملية حفظ موازية كتابة لقطة قديمة.
- لا تشغّل أداة initialize_neon_from_json.py على Neon التي تحتوي بالفعل على قاعدة CRM؛ هذه الأداة للتهيئة الأولى فقط.

## خطوة 1 — معاينة آمنة دون تعديل Neon
1. ضع `merge_latest_contacts_into_neon.py` في مجلد `Alrawasi_CRM_OneClick_Deploy` على Windows، مع الاحتفاظ بـJSON في `D:\Download\database\Backup` أو أي مجلد خاص بعيد عن GitHub.
2. افتح PowerShell داخل مجلد البرنامج، ثم نفّذ (الصق الرابط وحده عند مطالبتك، بلا إظهاره في صورة شاشة):

```powershell
$secureUrl = Read-Host "Paste TEST Neon URL" -AsSecureString
$env:DATABASE_URL = [System.Net.NetworkCredential]::new("", $secureUrl).Password.Trim().Trim("'", '"')
```

3. نفّذ المعاينة على مسار ملف JSON الذي حمّلته من النظام الأساسي:

```powershell
python .\merge_latest_contacts_into_neon.py "D:\Download\database\Backup\alrawasi_crm_snapshot_V7.5.48_20261013_185033.json"
```

أرسل الأرقام التالية فقط بدون أسرار:
- `NEON CURRENT CONTACT EVENTS`
- `JSON EXPORT CONTACT EVENTS`
- `ALREADY PRESENT`
- `MISSING CONTACT EVENTS TO ADD`
- `LOCAL ID REMAPS`
- `BLOCKING CONFLICTS`

المعاينة لا تكتب إلى Neon ولا إلى ملف JSON.

## خطوة 2 — الدمج بعد مراجعة المعاينة وتجميد الكتابة
لا تنفّذها حتى تتأكد من عدم وجود `BLOCKING CONFLICTS`، ومن عدم قيام أي مستخدم بإضافة تواصل في الخدمة التجريبية أثناء الدمج.

```powershell
python .\merge_latest_contacts_into_neon.py "D:\Download\database\Backup\alrawasi_crm_snapshot_V7.5.48_20261013_185033.json" --apply --backup-dir "D:\Download\database\Neon-Private-Backups"
```

سيطلب منك السكربت كتابة `MERGE TEST NEON`، ويحفظ لقطة Neon الحالية **مضغوطة وليست مشفّرة أمنيًا** (`.db.gz`) في مجلدك الخاص قبل الكتابة، ثم يحدث Neon فقط عندما يكون رقم المراجعة هو نفسه الذي قرأه عند بدء العملية.

**بعد النجاح:** أعد تشغيل خدمة Render التجريبية فورًا **قبل السماح بأي تعديل داخل البرنامج** لكي تستعيد أحدث لقطة، ثم نفّذ:

```powershell
python .\verify_neon_snapshot.py
```

**إذا ظهر أي تعارض:** لا تستخدم `--apply`، ولا تحذف Neon أو تستبدلها بالملف JSON. أرسل رسالة التعارض فقط للمراجعة.

## خطوة 3 — رفع تعديل الواجهات إلى GitHub
- بعد اختبار الدمج، ارفع ملفات V7.5.51 المعدلة داخل نفس المسار المستخدم حاليًا في GitHub:
  `Alrawasi_CRM_V7_5_50_GITHUB_CLEAN_LIGHT/Alrawasi_CRM_OneClick_Deploy/`
- لا تغير `Root Directory` في Render.
- Auto Deploy مضبوط عندك على Off: من Render اختر `Manual Deploy → Deploy latest commit` بعد اعتماد التعديلات.
- اختبر لون البطاقة، عداد الشركات الفريدة، عدد محاولات التواصل، وتقارير الشهر الحالي.

## حدود هذا الإصدار
التخزين المستخدم **لقطة SQLite كاملة داخل Neon**، وليس جداول PostgreSQL أصلية، ولذلك يجب منع التعديلات المتزامنة أثناء الدمج والاحتفاظ بنسخة احتياطية. هذه التعليمات مخصصة لبيئة اختبار منفصلة، ولم تُنفَّذ أي تغييرات على Neon الحية من هذه الحزمة.

## إصلاح المؤشر والتحذير في شاشة المدير
- الأيقونة السابقة (سحابة مشطوبة) تدل على تعطيل CONTACTS_DATABASE_URL القديمة، رغم وجود DATABASE_URL لحفظ لقطة CRM كاملة.
- الأيقونة الجديدة (سحابة مع علامة صح) تعني أن النظام يستخدم التخزين الخارجي المهيأ، وتشير التسمية عند تمرير المؤشر إلى نمط لقطات Neon الانتقالية.
- لن يظهر شريط أحمر أو أزرق متكرر في حالة التهيئة السليمة؛ يُظهر النظام تحذيرًا إذا كانت آلية التخزين الخارجي غير متاحة.
- **المؤشر لا يُعادل ضمانًا لحفظ كل طلب بنجاح**؛ تابع النسخ الاحتياطية واختبارات الاستعادة، فالنسخة ما تزال تعتمد على لقطات SQLite كاملة داخل Neon.
